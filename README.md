# Rizal Network Analysis App

![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=for-the-badge&logo=Streamlit&logoColor=white)
![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

An interactive web application built with **Streamlit** designed to perform Social Network Analysis (SNA) on datasets related to Jose Rizal’s correspondence and historical connections. This tool allows researchers and historians to visualize complex relationships, detect communities, and analyze individual nodes within a network.

## 🚀 Live Demo
You can access the hosted version of the app here: [rizalnetworkanalysis.streamlit.app](https://rizalnetworkanalysis.streamlit.app/)

---

## ✨ Features

- **Data Upload & Processing**: Support for CSV file uploads containing edge lists or connection data.
- **Community Detection**: Automated clustering to identify distinct groups or "circles" within the network (e.g., the Propaganda Movement, family ties, or European academic circles).
- **1st Degree Network Analysis**: Deep-dive into specific individuals to see their immediate connections and influence.
- **Interactive Visualizations**: Dynamic, zoomable, and draggable network graphs.
- **Sample Data Integration**: Option to use pre-loaded sample data for quick exploration.
